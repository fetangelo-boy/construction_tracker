# СтройТрекер — MVP трекера задач для строительной фирмы

Автономное веб-приложение (SPA) для управления строительными проектами. Реализовано по техническому заданию Construction Tracker TZ v1.0.

## Запуск

Откройте `index.html` в современном браузере. Сервер и установка зависимостей не требуются. Для полной работы с файлами через `file://` достаточно актуальных версий Chrome/Edge/Firefox.

Альтернативно — любой статический сервер, например:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Реализованные возможности

- **Проекты**: создание, статусы, период, адрес, заказчик, участники, этапы работ, отчёт по проекту.
- **Задачи**: создание, назначение, соисполнители, этапы, сроки, приоритеты, статусы, прогресс с историей изменений, зависимости FS.
- **Гант**: полосы по датам, FS-стрелки, цвета по статусам, масштаб день/неделя/месяц, фильтры, перетаскивание полос, подсветка конфликтов зависимостей.
  - Масштаб непрерывный (2–80 px/день): колесо мыши над диаграммой приближает/отдаляет **вокруг курсора**, Shift+колесо — горизонтальная прокрутка. Есть кнопки ±, ползунок и «Вписать». Preset'ы День/Неделя/Месяц задают фиксированную плотность.
  - **FS (finish-to-start)**: стрелка идёт от задачи-предшественника к зависимой. Зависимая задача не должна начинаться раньше дня, следующего за окончанием предшественника. При нарушении полоса и стрелка краснеют, а вверху появляется пояснение с количеством дней. Наведение на полосу или стрелку подсвечивает всю цепочку; клик по стрелке открывает зависимую задачу. В карточке задачи FS-зависимость можно изменить (роли с правом изменения сроков) — даты при этом подставляются автоматически; исключены циклические связи.
- **Командная работа**: комментарии, вложения (до 10 МБ на файл, до 20 на задачу), внутренние уведомления.
- **Роли и права**: руководитель, прораб/менеджер, исполнитель, наблюдатель. Проверка прав централизована в `js/store.js`.
- **Дашборд**: метрики, задачи по статусам, просроченные и близкие к сроку, загрузка исполнителей.
- **Аудит**: журнал изменений действий.
- **Данные**: сохраняются в `localStorage`, сброс демо-данных через меню пользователя.

## Смена роли

Нажмите на аватар в правом верхнем углу, чтобы выбрать пользователя с другой ролью и проверить ограничения прав.

## Структура

```
index.html          — каркас приложения
css/styles.css      — дизайн-система и адаптивная вёрстка
js/data.js          — демо-данные и справочники
js/store.js         — состояние, localStorage, права, аудит, уведомления
js/gantt.js         — диаграмма Ганта и проверка FS-конфликтов
js/app.js           — интерфейс, формы, карточка задачи, отчёты
```

## Ограничения MVP

Экспорт в Excel/PDF, email/Telegram-уведомления, критический путь, автопересчёт графика и серверное хранение, рекомендованные ТЗ, не входят в данную версию.
